01 · Service Lifecycle

기능보다 서비스의 전체 흐름을 봅니다.

설계, 구현, 배포, 관찰, 개선을 하나의 개발 과정으로 연결합니다.

  • 01

    Design

    요청과 데이터의 흐름을 먼저 정리합니다.

  • 02

    Build

    API와 데이터 구조를 실제 기능으로 구현합니다.

  • 03

    Deploy

    같은 실행 환경을 구성해 서비스로 공개합니다.

  • 04

    Observe

    로그와 동작을 기준으로 이상 징후를 확인합니다.

  • 05

    Improve

    원인을 좁히고 재발하지 않는 구조로 바꿉니다.
