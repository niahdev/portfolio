Project 01 · Data Service

게임 데이터를
다음 행동으로 바꿉니다.

ER-Dodge는 외부 게임 데이터를 수집·정규화하고 사용자 전적을 기준 통계와 비교해 다음 경기에서 실천할 행동을 제안하는 웹서비스입니다.

Node.jsExternal APIK3sTraefikOVHcloud
01 · OVERVIEW

통계를 나열하지 않고 판단에 필요한 정보만 남겼습니다.

사용자 전적과 티어·캐릭터 기준 데이터를 같은 구조로 정리한 뒤 차이를 비교합니다. 결과는 단순 수치가 아니라 다음 경기에서 바꿀 수 있는 행동 중심의 문장으로 제공합니다.

  • 외부 게임 API와 기준 데이터 수집·정규화
  • 사용자 전적과 기준 통계를 비교하는 분석 로직
  • 행동 제안 중심의 결과 구조와 예외 응답 처리
02 · ARCHITECTURE

수집, 분석, 제공, 운영의 경계를 나눴습니다.

외부 응답 형식이 바뀌어도 분석 로직 전체가 흔들리지 않도록 수집 단계에서 공통 모델로 변환합니다. 애플리케이션은 K3s Deployment로 실행하고 Traefik Ingress가 HTTPS 요청을 전달합니다.

Collect게임 API 응답 수집
Normalize공통 분석 모델 변환
Serve비교 결과와 행동 제안
03 · PROBLEM SOLVING

외부 API가 멈춰도 서비스 전체는 멈추지 않게 했습니다.

기준 데이터 API의 일시적인 오류가 분석 화면 중단으로 이어졌습니다. 실시간 응답에 직접 의존하던 구조를 자동 갱신, 마지막 정상 캐시, 번들 기본 데이터의 3단계 폴백 구조로 변경했습니다.

  • 정상 응답은 캐시에 저장하고 갱신 시각을 함께 관리
  • 갱신 실패 시 마지막 정상 데이터로 분석 지속
  • 캐시가 없는 초기 상태에서는 번들 데이터로 최소 기능 제공
04 · OPERATION

K3s에 배포해 공개 도메인으로 운영합니다.

OVHcloud VPS의 K3s에 Node.js 컨테이너를 Deployment로 실행하고 Service와 Traefik Ingress로 외부 요청을 연결했습니다.
