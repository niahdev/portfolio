Project 02 · Media Tool

목표 용량은 맞추고,
화질 손실은 통제합니다.

gif_lower는 사용자가 원하는 파일 크기를 입력하면 팔레트, FPS, 해상도를 단계적으로 탐색해 목표 이하의 GIF를 만드는 웹 도구입니다.

Node.jsFFmpegJob QueueDockerNginx
01 · OVERVIEW

사용자는 목표 용량만 결정하면 됩니다.

직접 FPS와 색상 수를 반복 조정하지 않아도 목표 크기를 기준으로 여러 압축 후보를 탐색합니다. 업로드, 작업 진행 상태, 결과 다운로드까지 하나의 흐름으로 구성했습니다.

  • 목표 용량 기반 다단계 압축 탐색
  • 업로드·백그라운드 작업·진행 상태·다운로드 API
  • 실패 응답과 임시 파일 수명 주기 관리
02 · COMPRESSION

모든 후보는 원본에서 다시 생성합니다.

이전 압축 결과를 다음 단계의 입력으로 사용하면 손실이 누적됩니다. 각 후보를 원본에서 다시 생성하고 팔레트, FPS, 해상도의 순서로 조건을 조정해 품질 저하의 범위를 예측할 수 있게 했습니다.

Palette색상 수 탐색
FPS프레임 빈도 조정
Resolution최종 해상도 조정
03 · OPERATIONS

무거운 작업이 서버 전체로 번지지 않게 했습니다.

FFmpeg 작업이 동시에 시작되며 CPU와 메모리가 고갈되는 문제를 확인했습니다. 작업 큐, 동시 실행 제한, IP별 생성 제한, 완료·실패 파일 자동 정리를 함께 적용했습니다.

  • 정해진 개수의 FFmpeg 작업만 동시에 실행
  • IP별 작업 생성 제한으로 요청 폭주 방지
  • 완료와 실패 시점에 임시 파일 자동 정리

전체 트러블슈팅 기록 보기 →

04 · DEPLOYMENT

Docker와 Nginx로 실제 서비스 중입니다.

FFmpeg가 포함된 실행 환경을 컨테이너로 고정하고 Nginx에서 업로드 크기, 요청 시간, HTTPS를 관리합니다. 현재 공개 도메인에서 직접 사용할 수 있습니다.
