Project 03 · Deployment System

어느 PC에서도
같은 순서로 실행합니다.

Student Progress Kiosk는 학생별 프로젝트 진행 상황을 조회·관리하는 현장형 시스템입니다. 공개 화면과 관리자 기능, 데이터베이스를 하나의 실행 구성으로 묶었습니다.

Node.jsMySQLDocker ComposeNginx
01 · OVERVIEW

공개 화면과 관리자 기능이 같은 데이터를 사용합니다.

학생, 프로젝트, 진행 단계, 피드백 데이터를 구조화하고 공개 키오스크와 관리자 CRUD 화면이 같은 데이터베이스를 바라보도록 구성했습니다.

  • 학생·프로젝트·진행 단계·피드백 데이터 구조
  • 조회 화면과 관리자 CRUD 기능
  • 애플리케이션·DB·프록시 통합 구성

MySQL 등록 실패 해결 기록 →

02 · PROBLEM SOLVING

수동 설치와 암묵적인 시작 순서를 없앴습니다.

PC마다 Node.js와 MySQL 설치 상태가 달랐고 DB보다 애플리케이션이 먼저 시작되면 연결 오류가 발생했습니다. App·DB·Nginx를 Compose로 묶고 헬스체크와 서비스 의존성을 명시했습니다.

Database헬스체크 통과
ApplicationDB 준비 후 시작
Nginx외부 요청 전달
  • 환경변수와 볼륨을 구성 파일로 명시
  • DB 준비 상태를 헬스체크로 확인
  • 신규 PC에서도 동일 명령으로 전체 서비스 실행
03 · RESULT

설치 설명이 아니라 실행 가능한 구성으로 전달합니다.

필요한 런타임과 서비스 순서를 코드로 남겨 환경 차이로 생기는 오류를 줄였습니다. 새로운 PC에서도 같은 명령과 같은 구성으로 재현할 수 있습니다.
